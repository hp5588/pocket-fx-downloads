# 口袋汇率 0.3.5

- 修复很小的单位换算比例显示为零的问题：仅在非零比例按两位小数四舍五入后为零时，逐位增加到最多四位，显示非零后停止。其他金额显示、输入限制与计算精度保持原规则。
- 首页锚定货币卡和金额输入面板的常用金额入口改为右上角的小黄色五角星。
- 金额输入框右侧新增常用金额下拉菜单，按保存顺序显示币种、金额和备注。选择专属金额时同时填入币种与金额，通用金额保留当前币种；确认换算后才应用，取消不更新主界面。
- 常用金额新增全局序号，支持长按金额条上下拖动。松手保存并结束拖动，取消手势恢复原顺序；重启后保留排序，下拉菜单使用同一顺序。新增金额放末尾、编辑保留位置、删除后序号自动连续。
