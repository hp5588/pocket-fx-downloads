# 口袋汇率 0.3.4

- 货币详情新增反向单位换算比例。正向和反向均按原始汇率计算，四舍五入显示两位小数；很小的比例可能显示为 0.00，内部换算精度保持。
- 新增「常用金额」：顶部输入区及各币种金额编辑面板均可使用。支持保存当前金额、手动新增、修改金额与备注，以及删除。
- 常用金额可绑定币种，也可设为任意输入币种都能使用的通用金额。选择时只填入数字，其他换算设置保持；在币种编辑面板中，仍需确认换算后才应用。
- 常用金额保存在本机，重启后保留。临时输入不会覆盖已保存的记录；「清除本机数据」会同时删除常用金额。
- 诗词内容增加「我相信会再次看到蓝天；鲜花挂满枝头」，画布按分号分成两行，并补齐四套内置字体的字形。

## 下载与安装

在下方 Assets 下载 `pocket-fx-0.3.4.apk`，适用于 Android 8.0 及以上版本。文件摘要见 `SHA256SUMS.txt`。

签名证书与 0.3.2、0.3.3 相同，可直接覆盖安装并保留本机数据。从 0.3.1 或更早版本升级时，需要先卸载旧版再安装；卸载会清除本机数据。
