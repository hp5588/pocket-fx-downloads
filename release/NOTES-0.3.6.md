# 口袋汇率 0.3.6

- 为锚定货币、换算货币和悬浮卡中的黄色五角星添加紧凑圆角背景。
- 诗词字体改为完整字库，修复自定义文字因按诗句裁剪字库而混用系统字体的问题。字体随安装包提供，离线可用；原字体未收录的字仍使用设备后备字体。安装包体积会增大。
- 内置诗词支持长按上下拖动，松手保存顺序，保留当前选中项；新增两行诗句「时来天地皆同力，远去英雄不自由」。
- 各常用金额入口均支持使用其他币种的金额，以条目币种为计算起点，顶部锚定币种保持不变。通用金额沿用当前输入币种。
- 常用金额下拉菜单使用浅色白底、深色黑底。

版本号 0.3.6，内部版本号 15。沿用 0.3.2 起的发布签名，可覆盖同签名版本并保留本机设置。

正式包与 0.3.6 试用包字节完全相同，已安装试用包无需重复安装。
